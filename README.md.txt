# «Каменный город, которого нет» — Кликабельный MVP

Атмосферный прототип игры с элементами ASMR. Проект представляет собой интерактивную веб-страницу, которая демонстрирует игровой процесс, настройки и аудио-сопровождение.

## 🚀 Как запустить
Просто откройте файл `index.html` в любом современном браузере (Chrome, Edge, Firefox).
*Для корректного воспроизведения звука рекомендуется сделать первый клик по экрану (это требование безопасности браузеров).*

## ✨ Реализованный функционал
- **Навигация:** Плавные переходы между 4 экранами с затемнением.
- **Настройки (сохраняются в браузере):**
  - Регулировка громкости музыки, звуков и ASMR-эффектов.
  - Изменение прозрачности текстовых плашек (от 0% до 100%).
  - Выбор размера шрифта (S, M, L, XL).
  - Выпадающие списки (графика и детализация).
- **Игровой процесс:**
  - Анимация сбора предметов (предмет летит в инвентарь).
  - Интерактивные подсказки с автозакрытием (через 5 секунд или по клику мимо).
- **Аудио-движок:**
  - Зацикленная фоновая музыка для каждого экрана с плавным кроссфейдом.
  - Звуковые эффекты при кликах, сборе предметов и выборе ответов.
- **Визуальные эффекты:** Рябь при клике, адаптивное масштабирование под размер окна.

## 🛠 Стек
- HTML5
- CSS3 (адаптивность на CSS-переменных)
- Vanilla JavaScript (без сторонних библиотек)
