# CLAUDE.md — Кликабельный прототип игры

## Цель проекта
Интерактивный кликабельный прототип игры с ASMR-уклоном. 
Реализованы 4 экрана, переходы, настройки (сохраняются в localStorage), анимация сбора предметов и полноценный аудио-движок (фоновая музыка и звуки).

## Стек и архитектура
- Нативный HTML + CSS + Vanilla JavaScript (без фреймворков).
- Масштабирование: базовый фрейм 576px, все элементы масштабируются через CSS-переменную `--scale`.
- Прозрачность плашек: через переменную `--panel-alpha`.

## Структура файлов
- `index.html` — вся верстка экранов.
- `styles.css` — стили. ВНИМАНИЕ: файл содержит жестко зафиксированные стили с `!important` для плашек, чтобы они не улетали. Не удаляй их без причины.
- `app.js` — вся логика: навигация, звук, localStorage, анимации.
- `design/` — фоны (PNG), вырезанные из Figma.
- `audio/` — музыка (bgm_*) и эффекты (sfx_*).

## ВАЖНЫЕ ПРАВИЛА ДЛЯ ИИ (НЕ ЛОМАТЬ)
1. **Не трогай CSS-координаты плашек**, если об этом не просят. Они выверены вручную.
2. **Текст масштабируется через JS**: функция `applyTextSize` ставит размер шрифта через `setProperty('font-size', ..., 'important')`. Не убирай `important`, иначе CSS перебьет размер.
3. **Аудио-движок**: музыка переключается в `goTo` через `playBGMForScreen`. Звуки кликов — через `playSFX`. Не дублируй вызовы.
4. **Сбор предметов**: анимация запускается функцией `collectItem`. Предметы помечаются `display: none`, чтобы звук не срабатывал дважды.

## Логика экранов
- **01-login**: переходы на 3-й (Продолжить) и 2-й (Настройки) экраны. Остальное — рябь.
- **02-settings**: ползунки громкости (1, 2, 3), ползунок прозрачности (4), кнопки S/M/L/XL, выпадающие списки. Кнопки выхода сохраняют (`data-save="true"`) или откатывают (`data-save="false"`) настройки.
- **03-task1**: предметы улетают в инвентарь (после сбора обоих — переход на 4). Подсказка с циклом из 2-х фраз.
- **04-task2**: три ответа ведут на 1-й экран. Подсказка «Подумай».
